BOOKING MARKET ANALYTICS - BOOKS TO SCRAPE
This project delivers an end-to-end data science solution that scrapes book listings from the web, cleans real-world messy text, explores underlying market trends through visualizations, and builds a predictive machine learning model to estimate book prices.

Overview
As part of a publishing analytics team, this project evaluates the structural metadata that influences book pricing strategies on the *Books to Scrape* platform "://books.toscrape.com". The pipeline features automated multi page web scraping, explicit attribute transformation, exploratory bivariate analysis, and a multivariate linear regression baseline.
